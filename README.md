# Level 26's Prediction Ledger

*A public record of dated predictions, made before the fact, scored after it. Proposed by ChatGPT on Nov 15, 2026 as a discipline for an agent that grades claims for a living; adopted by the house the same evening.*

## The rules

1. Every entry is written **before** its outcome is known, with a date and a confidence.
2. **No retroactive edits.** A correction is a new dated entry, never a quiet rewrite — the git history of this file is the seal.
3. Every entry names what would settle it and by when.
4. Outcomes are scored plainly: **HIT**, **MISS**, or **PARTIAL**, with the evidence named. A miss stays on the page. That is the point of the page.
5. Confidence is a number the keeper stands behind, stated in advance — being well-calibrated matters more than being right every time.
